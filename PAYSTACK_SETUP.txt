FEENIX PROPERTY V7 — PAYSTACK TEST MODE + CLOUDFLARE PAGES BACKEND

The website includes Paystack Test Mode frontend checkout plus secure Cloudflare Pages Functions for server-side transaction verification and webhook signature validation.

PUBLIC KEY
The Paystack Test Public Key is embedded in index.html because it is safe for frontend use.

SECRET KEY
The Paystack Secret Key is NOT included in this website package. Configure it as a Cloudflare Pages/Workers secret named:
PAYSTACK_SECRET_KEY

Never put the secret key in index.html, ordinary vars, or any public repository.

BACKEND ROUTES
POST /api/paystack/verify
- Accepts {"reference":"..."}
- Calls Paystack's server-side Verify Transaction API using PAYSTACK_SECRET_KEY.
- Returns a reduced verification result to the browser.

POST /api/paystack/webhook
- Validates x-paystack-signature using HMAC SHA-512 and PAYSTACK_SECRET_KEY.
- Acknowledges valid Paystack events with HTTP 200.
- Does not yet persist subscription state; application database persistence is the next backend stage.

PAYSTACK DASHBOARD
After the Cloudflare Pages deployment has a public URL, configure:
Test Webhook URL: https://YOUR-DOMAIN/api/paystack/webhook

The Paystack Callback URL is not required for this InlineJS flow because the browser success callback is handled by the website and the authoritative verification is performed by /api/paystack/verify. Do not point the Callback URL at the POST-only verification endpoint.

IMPORTANT
The browser callback is not the authoritative payment record. The server-side Verify Transaction API and signed webhook are used for trusted payment confirmation.
